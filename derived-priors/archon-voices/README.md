# archon-voices

Content about the **archons** — the named watchers/organs of the reading
instrument — kept here as data, never as code. The organs themselves live in
`eoreader7/native/organs/` (with the historical-figure carriers under
`eoreader7/native/archons/carriers/`); the surface (`the-fold`) carries none.

## `motto-quotes.json` — `ArchonMotto@1`

Twenty-one one-line expressions (19 located verbatim in their module, 2 flagged `located: false`), each: the line as the module states it (`q`),
where it is (`cite`), the archon's own term with transliteration, gloss and —
where added — non-Latin script (`translit`, `gloss`, `script`), where that
term is named (`origCite`), and the original work that would supply the
archon's own words (`need`).

It used to be the `ARCHON_QUOTES` array inside `the-fold/index.html`, feeding
a rotating motto on the chat hero. That hero was deleted (2026-09-23) and the
table became dead code; it moved here on 2026-09-28.

**Not** the archons' own words: these are the module authors' English lines
with the original-language expression beside them. The `need` field names the
work that would carry the archon's actual voice. Native-language voices, when
drawn, belong beside this file with their own giver and verification.
